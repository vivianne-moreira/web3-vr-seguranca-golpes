<h1 align="left">CyberAlert VR</h1>

**CyberAlert VR** é uma experiência interativa em Realidade Virtual acompanhada de uma landing page explicativa, desenvolvida para ensinar usuários leigos a identificar e descartar golpes na **Web 3.0** antes de realizar qualquer transação irreversível. Unindo imersão espacial (**Unity + Meta Quest**) com uma interface web moderna (**Vue 3 + TypeScript + Tailwind**), o projeto transforma segurança digital em memória muscular.

- 🛡️ **Proposta:** Treinar o reflexo físico de desconfiar antes de clicar em ambientes descentralizados.
- 🥽 **Mecânica VR:** Interação natural de *Grab* (pegar mensagens flutuantes com as mãos, inspecionar sinais de phishing/airdrops falsos e arremessar fraudes na lixeira).
- 🌐 **Experiência Web:** Landing page didática com simulador de golpes, explicação visual sobre custódia própria e guia da experiência VR.
- 🏗️ **Arquitetura:** Monorepo estruturado para integrar a aplicação VR, a plataforma web e a documentação do desafio.
- 🚀 **Deploy:** Aplicação web disponível online em [web3-vr-seguranca.vercel.app](https://web3-vr-seguranca.vercel.app/).
